# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate
- Giving constructive feedback
- Focusing on technical quality and user safety
- Supporting newcomers in a welcoming manner

## Enforcement

Project maintainers are responsible for enforcing this code of conduct. Violations may result in removal from the project community.
